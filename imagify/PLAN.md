# Implementation plan and evidence gates

1. **Portable engine — implemented.** Validate raster bytes and resource limits, encode WebP, retain the original if a full-size conversion is larger, preserve animation, and expose file, directory, and watch entry points. Use atomic output writes and a manifest so another project can adopt the package without the API.
2. **Automatic ingestion — implemented in code.** Direct upload, confirmed presigned upload, and replacement enqueue the default preset in their database transaction whenever the processor is configured. The existing worker scans the stored original, retries failed jobs, and keeps revisions and derived variants separate. Verify with the processor codec suite and the repository's S3Mock/ClamAV/API integration tests in an isolated local stack.
3. **Automatic delivery — implemented for new blog uploads.** An opaque token route selects a completed, smaller variant according to `Accept` and requested width, falls back to the scanned source, and sends short-lived selector redirects. New blog featured images use responsive `srcset`. Existing post URLs still require an explicit content migration. Measure response bytes and LCP against the live CDN before claiming visitor savings.
4. **Production evidence — operational gate.** Deploy the processor privately with a shared secret, set CPU and memory limits, ClamAV, object storage, and API environment, then test a real upload through delivery. Track queue age, success and failure counts, encoder time, output bytes, and effective bandwidth savings. Benchmark a representative corpus for quality, size, CPU, and decode cost. Promote a new preset only after those numbers and visual review support it.

The portable watcher automatically converts newly downloaded files placed in its configured local folder. The package is distributable as a versioned tarball for other Node projects. Production performance, quality, security, and availability claims need representative corpus benchmarks and a deployed end-to-end test; a code change alone cannot establish parity with another provider.

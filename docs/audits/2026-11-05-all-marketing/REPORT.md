# Public marketing audit — 2026-11-05

## Result

The audit expanded from About and Explosive Swings to the 56 concrete public URLs in [routes.json](routes.json), including marketing hubs, course/indicator/author details, legal pages, resource filters, calculator/share pages and redirect aliases. Repairs address wrong product content, unavailable tutorial links, publication loading, text clipping, unreadable contrast, motion preferences, animation cleanup and accessibility semantics. The [earlier report](../2026-11-05-marketing-pages/REPORT.md) retains the five original defect groups and their before/after evidence.

Delivery and final verification are recorded below. No production purchase, message, trade, account or content mutation was performed. The user explicitly authorized changelog updates, commit, push and squash merge, and confirmed `support@revolutiontradingpros.com` for both support and sales.

### Additional class-media and integration findings

M10 (P2): both public class pages immediately requested authenticated member downloads for anonymous visitors. The fixture intentionally refuses member endpoints; its 404 is not evidence that the real endpoint is missing. Source inspection confirms the real endpoint requires a user and returns `{ success: true, data: { downloads, is_enrolled } }`. Public pages now show a sign-in link instead of issuing that request. The tax-class downloads section also incorrectly treated `data` itself as an array; it now reads/validates `data.downloads`, with two component regressions for the real shape and malformed responses.

M11 (P2): the two configured class S3 origins were absent from media-src, so the browser blocked every recording before contacting the host. Exact-origin additions preserve the existing source URLs and approval policy. Quickstart's existing MP4 returns 200 to HEAD; the tax recording inspected returns 403 from S3. Both players now expose failure and retry visibly. A shared attachment captures non-bubbling source failures and checks the initial media error/network state, including failures before hydration; the controlled 403/retry browser regression failed before that hydration repair and passes afterward. The host's denied files require an authorized replacement/source change outside this code repair; successful tax-recording playback is not claimed. The class SEO VideoObjects also contained dates with no visible source and (Quickstart) a different media URL; those unsupported nodes were removed. No publication dates were invented.

M12 (P2): Courses and Rooms fetched decorative noise from third parties that returned ORB/402 failures. Both now use the existing `/textures/noise.svg`. The Rooms animation controller targeted missing hero/particle selectors; correct route-scoped hero targets and guards remove those warnings. A cold client-navigation race in the audit itself was identified separately: it checked the outgoing main immediately after a link click. Destination URL readiness now precedes DOM readiness; those interrupted instrumentation results are superseded by the rerun.

## Limits

The installed Kit 3 runtime declares `$app/env` and deprecates `$app/environment`; existing runtime-flag imports are retained rather than introducing a deprecated module.

Coverage is anonymous Chromium, production output and owned API fixtures. This does not verify authenticated member/admin/checkout flows, purchases, payment providers, real video playback, production publication database contents, mailbox delivery, other browser engines, a heap-leak proof, financial outcomes or the truth of existing business claims. No production maintenance setting was changed. Actual live deployment verification is conditional on observing an authorized deployment of the merged revision; local production verification alone is not represented as deployed behavior.

## Standards used

Repository AGENTS/SEO contract and installed Svelte documentation establish the ownership and rendering requirements. [Svelte attachments](https://svelte.dev/docs/svelte/@attach) and [lifecycle](https://svelte.dev/docs/svelte/lifecycle-hooks) describe setup/cleanup. [W3C contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [Pause, Stop, Hide](https://www.w3.org/WAI/WCAG21/Understanding/pause-stop-hide.html), and [ARIA tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/), [media error events](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/error_event) and [media network state](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/networkState) support the measurable contrast, motion and keyboard expectations. These support technical acceptance, not a legal compliance certification.

# Technical SEO Standard — Svelte 5 / SvelteKit

**Verified:** 2026-10-31
**Scope:** Technical SEO only. This standard makes every page crawlable, indexable, fast, and eligible for rich results. Rankings beyond that depend on content and links. SvelteKit's own SEO page says: _"The most important aspect of SEO is to create high-quality content that is widely linked to from around the web."_

## How to read this document

- Every requirement has an **ID** (e.g. `IDX-05`). The audit prompt (`seo-audit.md`) reports PASS / FAIL / N-A / BLOCKED per ID, per URL or template, with evidence.
- **Source** shows where the requirement comes from:
  - `SK:<page>` — svelte.dev/docs/kit/<page>, re-fetched 2026-10-31.
  - `G:<topic>` — Google Search Central documentation.
  - `[house rule]` — an engineering choice, not a Google or Svelte requirement. It is labelled so nobody mistakes it for one.
- Items marked **†** were not re-fetched on 2026-10-31. The audit agent **must fetch the cited page** before relying on them.
- **Version caveat:** SvelteKit 3 went stable in October 2026, and the Svelte MCP docs now describe it (e.g. `$app/env`, `#lib/...`). A repo may still be on 2.x, where those are `$app/environment` and `$lib`. Always use the APIs of the version **installed in the repo** (see `package.json` and the lockfile). Migrating to 3 (`npx sv migrate sveltekit-3`) is a separate, owner-approved task, not part of this audit. SvelteKit 3 changes that matter here: Node 22 and Vite 8 minimums; adapter-node replaces the `ORIGIN` env var with `kit.paths.origin`; `base` and `assets` are removed from `$app/paths`; shallow routing moves from `pushState`/`replaceState` to `goto(..., { state })`; `@sveltejs/enhanced-img` 1.x requires Vite 8.

## 10. YMYL and trust (YMYL) — mandatory for trading, finance and investing content

Google says that for topics affecting health, finances, safety or societal well-being, its systems "give even more weight to content that aligns with strong E-E-A-T", and that trust is the most important part of E-E-A-T. E-E-A-T is not a ranking factor itself. These requirements make trust **visible and verifiable**. The agent can check that the elements exist; the owner must confirm they're true.

| ID      | Requirement                                                                                                                                                                                                                                                                                                                       | Source                                                   | Verify                                                  |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------- |
| YMYL-01 | **Who:** every article, analysis, lesson and trade alert carries a visible byline linking to an author page.                                                                                                                                                                                                                      | G:helpful-content (fetched 2026-10-31)                   | Crawler: byline + link on every article URL             |
| YMYL-02 | **Author pages:** real name, photo, verifiable background (trading experience, roles, credentials that actually exist), links to external profiles (`sameAs`), and the list of the author's content. `ProfilePage` + `Person` JSON-LD. **No invented names, AI headshots or fake credentials** — Google names these as deception. | G:helpful-content; G:profile-page †                      | Crawler presence; REQUIRES-HUMAN truth check            |
| YMYL-03 | **How:** articles disclose how the content was made, including any AI or automation use, where readers would expect it. Performance claims state methodology (period, sample, whether hypothetical or backtested).                                                                                                                | G:helpful-content                                        | Content review — REQUIRES-HUMAN                         |
| YMYL-04 | **Why:** content exists to help readers, not to capture search traffic. No pages built only to target keyword variants (see SPAM-02 doorways).                                                                                                                                                                                    | G:helpful-content                                        | Inventory review: near-duplicate template pages flagged |
